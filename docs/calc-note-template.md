# 计算书模板 v0.1（2026-10-17）

> README 专业性清单："每份 RFQ 回复附正式计算书……交互工具是计算书的脸，计算书是骨头。"
> 每份计算书同时产出两个文件：`calc-note.md`（人读，脱敏版上官网）与 `calc-note.json`
> （机器读，可 diff、可归档重算——AI-native：计算书也是数据，不是散文）。
> 生成器未来挂 CLI：`p0 doc --in case.json`（AI-native 落地表的延伸）。

## C. 输入数据登记表（逐项来源与不确定度）

每条用到的曲线/常数一行：

| 引用 id | 器件 | 来源 URL | 等级 | 不确定度 | 工质基准 | 备注 |
|---|---|---|---|---|---|---|

**硬规则**：任何 redlight（无源占位）条目参与计算 → 整份计算书结论标"未验证"，禁止进 proposal（guarantee-interface §4）。

## D. 模型与假设登记表

逐条列：网络拓扑假设（manifold 理想分配 vs 实测不平衡度 10%）、物性处理（均值温度 vs 分段）、摩擦公式（Haaland + 层流 64/Re、Re<2300 判据、粗糙度取值）、干管单程×2、忽略项（重力位差、热泄漏、瞬态）。每条带：影响方向与量级估计。

## E. 结果（对齐 guarantee-interface §2/§3 承诺参数）

- 承诺参数表：每支路 min 保证流量与裕度、泵工作点（Q/H/频率）、NPSH 裕量、总流量；
- 守恒残差与收敛状态（残差 ≥1e-8 → 不允许出数）；
- 数据等级汇总：sourced 几条、redlight 几条、redlight 影响哪些结论。

## F. 敏感性分析表（README：每次输出的组成部分，不是可选件）

对关键输入（泵曲线 ±、各支路 K ±10%、工质温度 ±5°C、堵塞漂移）批量重算，
输出各承诺参数的响应区间。数据来自 `p0 solve` 批量工况（将来：`p0 sweep`）。

## G. 故障与退化场景（标配）

1. 单支路关断再分配：其余支路 min 裕度；
2. 过滤器堵塞漂移扫描：min 裕度归零点（维护周期建议输入）；
3. 部分负载（P1 后补热侧）。

## H. 安全系数与不承诺事项

- 采用的安全系数及依据；
- 负契约引用（guarantee-interface §4 原文照录）：不承诺 die 级、服务器内部、房间级气流、redlight 参与项。
