# 承诺接口（guarantee interface）正式定义 — v0.1 草案（2026-10-17）

> 依据 README 铁律：**仿真边界 = 承诺边界**。本文件定义"我们敢写进 proposal 的数字"
> 的精确含义：哪些参数、在哪个物理位置、以什么形式承诺。P0/P1 求解器的输出契约、
> 盲算测试向量、RFQ 计算书模板都以本文件为上游——任何输出字段若不能映射到本文件
> 的某条承诺参数，就是过度计算；任何承诺参数没有对应的验证向量，就是虚承诺。
>
> 状态：v0.1 草案。标注 `〔待曲线库〕` 的数值需在首批调研（6 路 fan-out）落地后复核。

## 1. 承诺面的物理位置

```
CDU 泵 → 供液干管 → 机柜 manifold → ┃UQD 耦合面┃ → 服务器冷板组 → 回液 → CDU 换热器
                                    ▲ 承诺面（供液侧）
```

- **承诺面 = 每路 UQD 供液侧接口**（per ORv3 机柜入口）。
- UQD 之后（服务器内部管路、冷板微通道、die）不在承诺范围——服务器厂商的保证域。
- 机柜外部（房间气流、干冷器）不在 P0/P1 承诺范围（P4 按需外购）。

## 2. 承诺参数（P0：水力）

### 3.3 v0.1 范围缺口（正式报价前逐项补，README/类型头注同步）

- `T_fluid_max` 与冷板最小流量保证字段（冷板库 redlight：无公开数据）；
- 室内排热模型（room 现仅用于露点；35 °C 排热主张待 P4 房间级咨询衔接）；
- capturePct 实测标定（现仅 OCP 70–75% 文献口径）。

## 4. 负契约（明示不承诺）

- die→cold plate 热行为（服务器厂商域）；
- 服务器内部管路压降（含在厂商 UQD/冷板规格内）；
- 房间级气流与热回流（P4 外购咨询）；
- **任何 redlight（无源）数据参与计算的输出**——整体标注"未验证"，禁止进 proposal。

## 5. 单位纪律（沿用 README：入库一律 SI 实用单位）

流量 L/min、压强 kPa、温度 °C、功率 W、扬程 m。换算只发生在 IO 边界一次；
求解器内部统一国际单位制（m³/s、Pa、K），输入输出层负责转换。

### 数值语义细则（2026-10-18 二轮评审后回写）

- **曲线 x 域为闭区间**：工作点恰落在端点上属域内、允许出数；判越界前容让收敛
  误差 1e-6·x_max，避免把端点真根误判为越域（review-p0-v2.0 m1）。
- **摩擦系数连续性**：层流（64/Re）→ 过渡带（2300–4000 线性内插）→ Haaland，
  f(Re) 全域连续——压降跳变会造成"间隙根"假收敛（review-p0-v2.0 M1）。
- 求解器 = Illinois（超线性）+ 二分兜底（病态/折点根的几何收敛保证）。

## 6. 验收判据（数字敢写进 proposal 的全部条件）

1. `solver.residual < 1e-8`（P0）/ `solver.p1_fixed_point_step ≤ 1e-8`（P1 定点末步差，
   实现停机 1e-12），且 NaN 守卫通过；
2. 该工况涉及的全部器件曲线为 sourced 等级（无 redlight 参与）；P1 侧另须满足 §3.2
   假设登记表的域守卫（物性域/LC25 许用与沸点/hx 流量带宽/θ 数据域/热力学可行性，
   任一命中 = converged=false = 不允许出数）；
3. 金向量测试全绿（`p0 vectors` / `p1 vectors` 退出码 0）；
4. 敏感性表完整：每个承诺参数附 ±10% 关键输入扰动的响应；
5. 归档 `{inputs, solverVersion, dataVersion}`，可一字不差重算。

## 7. 变更管理

本文件 semver：承诺参数的新增/收紧 = minor，删减/放松 = major（需要重新审视已发报价）。
每次变更登记在 git 历史并在计算书引用其版本。
